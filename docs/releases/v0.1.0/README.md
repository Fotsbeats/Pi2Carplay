# v0.1.0 build and verification records

These records describe the flashable image and its build inputs. They are not needed by Raspberry Pi Imager. The image is the only uploaded asset in the v0.1.0 release.

The complete patched kernel source is on main at `src/kernel/linux`; build inputs and instructions are in `src/kernel`. `source-manifest.json` is the original build-input snapshot at its recorded commit, not a rolling inventory of this repository. `SHA256SUMS` provides the image checksum.
